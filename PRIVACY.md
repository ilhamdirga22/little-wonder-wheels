# Privacy — Little Wonder Wheels 2.0

This prototype does not require an account, display ads, collect analytics, or intentionally send player data to a game backend. Gameplay progress and settings are stored locally in browser localStorage. The user may clear browser site data or reset progress in Settings.

The game loads the Three.js library from jsDelivr or esm.sh; those providers may receive standard network metadata such as IP address and browser headers. Browser speech synthesis is optional and may be implemented by the browser or operating system; availability and handling depend on the platform. GitHub Pages hosting may process ordinary server logs.

This file is a development disclosure, not a substitute for a reviewed public privacy policy. Before broad publication, verify actual hosting, third-party dependencies, and applicable child-directed-app rules.
